1. **P1 — Promise publication overwrites existing files and exposes partial output.** [promise.rs:102](/Users/daniel/Work/splice-file-work/macos/crates/splice-platform/src/macos/promise.rs:102) calls `std::fs::copy` directly onto AppKit’s destination. A collision truncates existing data; disk-full errors leave partial output. The short-copy branch can then delete that destination. **Fix:** write a private sibling staging file, verify and sync it, then publish to the exact supplied basename using an atomic no-replace rename. Remove only owned staging on failure.

2. **P1 — The native copy has no receipt ownership, cancellation, or service-visible completion.** [files.rs:167](/Users/daniel/Work/splice-file-work/macos/crates/splice-platform/src/files.rs:167) returns only `PathBuf`; [promise.rs:90](/Users/daniel/Work/splice-file-work/macos/crates/splice-platform/src/macos/promise.rs:90) starts the destination copy afterward. Releasing `ReceivedLease` at `writer.complete()` permits `ClearReceived` during this copy. Once copying starts, no cancellation signal reaches it, and destination errors reach AppKit but never core/shelf state. **Fix:** return an owned carrier such as `PromiseSource { path, access: Arc<dyn Send + Sync> }` containing the core lease. Hold it through publication and the native completion callback. Add cancellation checked between chunks and a `PromiseFinished { attempt, root, result }` event. The channel’s atomic guard already correctly prevents duplicate replies.

Preserve Reveal access to partial published results and expose every active transfer’s cancellation.
